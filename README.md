# ☁️ Cloud Deployment Lab — Next.js + GitHub + Vercel

Aplicación web desarrollada con **Next.js** para implementar y demostrar un flujo completo de desarrollo, control de versiones, integración continua y despliegue en la nube utilizando **Git**, **GitHub** y **Vercel**.

El proyecto fue desarrollado en el contexto de la asignatura **Cloud Computing** del programa de Ingeniería de Sistemas de la Universidad de Antioquia.

---

## 🌐 Demo

La aplicación se encuentra desplegada públicamente en Vercel:

**Production:**  
https://cloud-lab-udea.vercel.app

---

## 📌 Descripción

El objetivo del proyecto es implementar el ciclo completo de publicación de una aplicación web moderna, partiendo desde un entorno de desarrollo local hasta disponer de una versión accesible públicamente desde Internet.

El flujo implementado es:

```text
Local Development
      │
      ▼
   Next.js
      │
      ▼
     Git
      │
      ▼
    GitHub
      │
      ▼
    Vercel
      │
      ▼
Production Deployment
